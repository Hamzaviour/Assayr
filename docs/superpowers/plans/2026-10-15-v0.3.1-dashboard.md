# v0.3.1 Dashboard, Theme, Compliance Page and Risk Owners Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebrand Assayr in maroon/white, replace the dashboard with a clean Vanta-style overview (framework compliance with partial progress, monitoring cards, charts), add a Compliance page, and let users assign risk owners.

**Architecture:** One new read-only backend endpoint `GET /api/v1/dashboard` computes every dashboard number (framework rows, status counts, evidence attention, risk status buckets, risk levels, unowned controls, trend) so the mapping is tested in Python. The frontend gets four small dependency-free SVG chart components with text alternatives, a rewritten `DashboardPage`, a new `CompliancePage`, and an owner picker built on the existing `usePeople` hook and `PATCH /risks/{code}`.

**Tech Stack:** FastAPI + SQLAlchemy + pytest; React 19 + TypeScript + TanStack Router/Query + Tailwind v4 tokens + Vitest/Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-15-v0.3.1-dashboard-design.md`

## Global Constraints

- Brand: `--primary` light `#8A1538`, hover `#6F102C`, soft `#F7E8ED`, on-primary `#FFFFFF`; dark `--primary` `#E0577C`, hover `#EA7A98`, soft `#3A1220`, on-primary `#1A0610`; light canvas `#F7F5F6`.
- Status colours (`--ok --warn --bad --review --idle --na`) unchanged.
- Chart palette tokens `--chart-1`..`--chart-6`: maroon, teal, amber, slate-blue, green, grey.
- Risk buckets: Open = draft, assessed, review_due, reassessing; In progress = treatment_planned, in_treatment; Closed = treated, accepted, closed.
- "Readiness by Annex A theme" no longer appears on the dashboard.
- No chart library: charts are in-house SVG with a visually hidden data table each.
- Framework names render bold.
- No NIA placeholder card.
- WCAG AA contrast for text on surfaces in light and dark; no horizontal scroll at 360 px.
- Commits have no `Co-Authored-By` trailer. Backend commands run from `backend/` with `uv run`; frontend from `frontend/` with `npx vitest run`.

## Review Focus

1. **A brand-new install with no evidence and no risks** — dashboard shows zeros and a next-step hint, never "NaN%", empty bars or a broken chart; test in Tasks 3 and 5.
2. **Closed risks** — the risks list hides closed ones by default, but the dashboard must count them in "Closed"; test in Task 3.
3. **Superseded evidence** — replaced files must not count as needing attention; test in Task 3.
4. **A user without risk-read permission** (e.g. control owner only) — dashboard still loads, risk card shows nothing rather than an error; test in Task 3.
5. **Owner picker with a deactivated owner** — a risk whose owner was deactivated still shows that name, and choosing "Unassigned" clears it; test in Task 7.

```python
"""One call with every number the dashboard shows."""

import uuid
from collections import Counter
from datetime import date, timedelta

from fastapi import APIRouter, Depends, Request
from pydantic import BaseModel
from sqlalchemy import select
from sqlalchemy.orm import Session

from assayr.catalogue.models import Control, EvidenceSlot, Framework
from assayr.catalogue.router import resolve_scope
from assayr.db import get_session
from assayr.evidence.models import ArtefactLink
from assayr.identity.deps import current_user, get_clock, require
from assayr.identity.models import User
from assayr.identity.rbac import Grant, Perm, has_perm
from assayr.risk.models import Risk
from assayr.risk.service import risk_row
from assayr.scoring.models import ScoreSnapshot
from assayr.scoring.service import scope_has_evidence, weighted_readiness

router = APIRouter(tags=["dashboard"])
TREND_DAYS = 90
OPEN = {"draft", "assessed", "review_due", "reassessing"}
IN_PROGRESS = {"treatment_planned", "in_treatment"}
CLOSED = {"treated", "accepted", "closed"}


class FrameworkRow(BaseModel):
    code: str
    name: str
    version: str
    total: int
    compliant: int
    readiness: float | None
    status_counts: dict[str, int]


class EvidenceCard(BaseModel):
    needs_attention: int
    ok: int
    total: int


class RiskCard(BaseModel):
    open: int
    in_progress: int
    closed: int
    total: int
    by_level: dict[str, int]


class TrendPoint(BaseModel):
    date: date
    readiness: float


class DashboardOut(BaseModel):
    frameworks: list[FrameworkRow]
    evidence: EvidenceCard
    risks: RiskCard | None
    unowned_controls: int
    trend: list[TrendPoint]


@router.get("/dashboard", response_model=DashboardOut)
def dashboard(
    request: Request,
    user: User = Depends(current_user),
    grant: Grant = Depends(require(Perm.CONTROLS_READ)),
    db: Session = Depends(get_session),
    scope_id: uuid.UUID | None = None,
) -> DashboardOut:
    scope = resolve_scope(db, scope_id, grant)
    controls = list(db.scalars(select(Control).where(Control.scope_id == scope.id)))
    counts = Counter(c.status for c in controls)
    framework = db.scalar(select(Framework).order_by(Framework.created_at))
    row = FrameworkRow(
        code=framework.code if framework else "iso27001",
        name=framework.name if framework else "ISO/IEC 27001",
        version=framework.version if framework else "2022",
        total=len(controls),
        compliant=counts.get("compliant", 0),
        readiness=weighted_readiness(controls) if scope_has_evidence(db, scope.id) else None,
        status_counts=dict(counts),
    )
    states = Counter(
        db.scalars(
            select(ArtefactLink.state)
            .join(EvidenceSlot, ArtefactLink.slot_id == EvidenceSlot.id)
            .join(Control, EvidenceSlot.control_id == Control.id)
            .where(Control.scope_id == scope.id, ArtefactLink.state != "superseded")
        )
    )
    evidence = EvidenceCard(
        needs_attention=states.get("in_review", 0) + states.get("rejected", 0),
        ok=states.get("accepted", 0),
        total=sum(states.values()),
    )
    risks = None
    if has_perm(user, Perm.RISKS_READ, scope.id):
        rows = [risk_row(db, r) for r in db.scalars(select(Risk).where(Risk.scope_id == scope.id)).unique()]
        statuses = Counter(r.status for r in rows)
        levels = Counter(
            (r.current or r.inherent).band for r in rows if (r.current or r.inherent) is not None
        )
        risks = RiskCard(
            open=sum(statuses[s] for s in OPEN),
            in_progress=sum(statuses[s] for s in IN_PROGRESS),
            closed=sum(statuses[s] for s in CLOSED),
            total=len(rows),
            by_level=dict(levels),
        )
    since = get_clock(request)() - timedelta(days=TREND_DAYS)
    snapshots = db.scalars(
        select(ScoreSnapshot)
        .where(ScoreSnapshot.scope_id == scope.id, ScoreSnapshot.taken_at >= since)
        .order_by(ScoreSnapshot.taken_at)
    )
    return DashboardOut(
        frameworks=[row],
        evidence=evidence,
        risks=risks,
        unowned_controls=sum(1 for c in controls if c.owner_id is None),
        trend=[TrendPoint(date=s.taken_at.date(), readiness=s.readiness) for s in snapshots],
    )
```

`Donut.tsx` (circumference arcs with `stroke-dasharray`):
```tsx
import { DataTable } from "./DataTable"
import type { Segment } from "./StackedBar"
export function Donut({ segments, label, centre }: { segments: Segment[]; label: string; centre?: string }) {
  const r = 42, c = 2 * Math.PI * r
  const total = segments.reduce((s, x) => s + x.value, 0)
  let offset = 0
  return (
    <figure className="flex flex-col items-center gap-2">
      <svg viewBox="0 0 100 100" className="size-40" role="img" aria-label={label}>
        <circle cx="50" cy="50" r={r} fill="none" stroke="var(--subtle)" strokeWidth="12" />
        {total > 0 && segments.filter((s) => s.value > 0).map((s) => {
          const len = (s.value / total) * c
          const el = (
            <circle key={s.key} cx="50" cy="50" r={r} fill="none" stroke={s.color} strokeWidth="12"
              strokeDasharray={`${len} ${c - len}`} strokeDashoffset={-offset} transform="rotate(-90 50 50)" />
          )
          offset += len
          return el
        })}
        {centre && <text x="50" y="55" textAnchor="middle" className="fill-[var(--text)] text-[15px] font-bold">{centre}</text>}
```

```tsx
import { DataTable } from "./DataTable"
export function LineChart({ points, label, yMax = 100, format = (y) => String(y) }:
  { points: { x: string; y: number }[]; label: string; yMax?: number; format?: (y: number) => string }) {
  const w = 300, h = 120, pad = 6
  const xs = (i: number) => (points.length > 1 ? pad + (i * (w - 2 * pad)) / (points.length - 1) : w / 2)
  const ys = (y: number) => h - pad - (Math.min(y, yMax) / yMax) * (h - 2 * pad)
  const line = points.map((p, i) => `${i ? "L" : "M"}${xs(i).toFixed(1)},${ys(p.y).toFixed(1)}`).join(" ")
  const area = points.length ? `${line} L${xs(points.length - 1).toFixed(1)},${h - pad} L${xs(0).toFixed(1)},${h - pad} Z` : ""
  return (
    <figure>
      <svg viewBox={`0 0 ${w} ${h}`} className="h-32 w-full" preserveAspectRatio="none" role="img" aria-label={label}>
        {[0.25, 0.5, 0.75].map((f) => <line key={f} x1="0" x2={w} y1={h * f} y2={h * f} stroke="var(--line)" strokeWidth="1" />)}
        {points.length > 0 && <path d={area} fill="var(--primary-soft)" />}
        {points.length > 0 && <path d={line} fill="none" stroke="var(--chart-1)" strokeWidth="2.5" vectorEffect="non-scaling-stroke" />}
        {points.map((p, i) => <circle key={p.x} cx={xs(i)} cy={ys(p.y)} r="2.5" fill="var(--chart-1)"><title>{`${p.x}: ${format(p.y)}`}</title></circle>)}
      </svg>
      <DataTable caption={label} rows={points.map((p) => [p.x, format(p.y)])} />
    </figure>
  )
}
```
