# v0.4.1 Internal Audits Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Internal auditors run ISO 27001 and NIA internal audits in Assayr and export/import them in the organisation's "NIA - IA report" workbook layout.

**Architecture:** New backend module `assayr.audits` (models, schemas, service, workbook, router) with one Alembic migration; ISO refs come from `Control` rows (excluding `NIA ` own controls), NIA refs from `nia_views`. Excel via the existing `openpyxl` dependency and `exports.xlsx_response`. Frontend adds `/audits` and `/audits/$id` pages and makes the "Audits" nav item live.

**Tech Stack:** FastAPI, SQLAlchemy 2, Alembic, openpyxl, pytest; React 19, TanStack Router/Query, Tailwind v4, Vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-16-v0.4.1-internal-audit-design.md`

## Global Constraints

- Audit results never change control status.
- No NCSA wording in repo or tests: assessment areas in tests are invented text.
- Export header row exactly: `Sr. No.` | `Domain Name` | `Sub Domain Name` | `NIA Control` (ISO: `ISO Control`) | `Control Description/Assessment Area` | `Design Assessment (DA) / Operating Effectiveness Assessment (OEA) / Both` | `Mandatory (M) / Additional (A)` | `Control status (Pass/Fail/Partial)`; sheet `NIA - IA report` / `ISO - IA report`.
- Writes need new permission `audits:write` (isms_manager, internal_auditor); reads need `controls:read`; reopen needs `controls:write` + reason.
- Completed audit: every write → 409 "This audit is completed. Reopen it to make changes."
- Import: max 5 MB, max 2,000 rows; missing header → 422, nothing created.
- Backend gate: `uv run ruff check . && uv run ruff format --check . && uv run pytest -q -W error`; frontend gate: `npx tsc --noEmit -p . && npx vitest run`.
- Commits: explicit `git add <paths>`, no co-author trailers.

## Review Focus

1. **A workbook whose header has extra spaces, line breaks or different case** — columns are still found; test in Task 3.
2. **A workbook row with a ref like "SU5" or " su 5 "** — normalised to `SU 5` before matching; test in Task 3.
3. **Adding the same controls twice** (all, then a domain) — no duplicates, no 500; test in Task 2.
4. **A control-owner or viewer trying to record results** — 403; test in Task 2.
5. **An audit with no items being completed** — refused (409 "Add controls before completing"); test in Task 2.

class Audit(IdMixin, TimestampMixin, Base):
    __tablename__ = "audit"
    scope_id: Mapped[uuid.UUID] = mapped_column(ForeignKey("scope.id", ondelete="CASCADE"))
    framework: Mapped[str] = mapped_column(String(20))

    period_end: Mapped[date | None] = mapped_column(Date)
    auditor_id: Mapped[uuid.UUID | None] = mapped_column(ForeignKey("user_account.id", ondelete="SET NULL"))

    completed_by_id: Mapped[uuid.UUID | None] = mapped_column(ForeignKey("user_account.id", ondelete="SET NULL"))
    auditor / completed_by relationships (lazy="joined"); items relationship ordered by sort_order, cascade="all, delete-orphan"

class AuditItem(IdMixin, Base):

    __table_args__ = (UniqueConstraint("audit_id", "ref", name="uq_audit_item_audit_ref"),)
    audit_id (FK audit.id CASCADE), ref String(20), sort_order Integer,
    domain String(200), sub_domain String(200), assessment_area Text|None,
    test_type String(10)|None, requirement String(1)|None, result String(10)|None, notes Text|None
