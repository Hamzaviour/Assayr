# v0.5 Training and Awareness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ISMS managers publish training courses with an auto-marked assessment, assign them to staff (Assayr accounts imported from CSV), track completion and export evidence; staff complete "My training".

**Architecture:** Identity gains `department`, `must_change_password`, CSV import and a password-change endpoint with a gate. New backend module `assayr.training` (models, schemas, service: assignment/marking/recurrence, routers for manager and `/my`), one Alembic migration `0008_training`, a `training_sweep` job enqueued on the worker's periodic tick. Frontend adds first-sign-in password screen, Users CSV import, Training manager pages, My training player and assessment, and a dashboard card.

**Tech Stack:** FastAPI, SQLAlchemy 2, Alembic, openpyxl, pytest; React 19, TanStack Router/Query, Tailwind v4, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-16-v0.5-training-awareness-design.md`

## Global Constraints

- No email/SMS. Temporary passwords: 16 random characters, returned once in the import response, never logged or stored in plain text; users get `must_change_password = true`.
- Password gate: while `must_change_password`, every API call except `GET /auth/me`, `POST /auth/logout`, `POST /auth/password` returns 403 "Change your temporary password first."
- Choice questions only: `single`, `multiple`, `true_false`; a question scores only if the chosen set equals the correct set; employee views never contain `is_correct`.
- Defaults: pass mark 80, max attempts 3, shuffle true, recurrence 12 months, due 30 days, training upload limit 500 MB (`training_upload_mb`).
- Uploads: mp4, webm, pdf, pptx, docx only (sniffed); video served with HTTP Range; `nosniff`.
- Drive URLs: `https://drive.google.com/file/d/<id>/...` or `https://drive.google.com/open?id=<id>`; stored as id; preview `https://drive.google.com/file/d/<id>/preview`. CSP gains `frame-src https://drive.google.com` in `frontend/site.caddy` and `backend/src/assayr/windows/render.py`.
- Permission `training:manage` for `isms_manager`; everyone signed in uses `/my/...` for their own assignments only.
- Gates: backend `uv run ruff check . && uv run ruff format --check . && uv run pytest -q -W error -o addopts=""`; frontend `npx tsc --noEmit -p . && npx vitest run`.
- Commits: explicit `git add <paths>`, no co-author trailers. All test content invented.

## Review Focus

1. **A CSV saved by Excel** (UTF-8 BOM, semicolon separator, CRLF, trailing blank lines) — imports cleanly; test in Task 1.
2. **Two assignment requests for the same people** (all, then a department) — no duplicate open assignments; test in Task 4.
3. **An employee submitting answers for a question not in the assessment, or an option from another question** — ignored/422, never scored as correct; test in Task 4.
4. **Submitting after the attempts are used up, or before the materials are confirmed** — 409 with a clear message; test in Task 4.
5. **An employee calling manager endpoints or another person's assignment** — 403/404; test in Task 4.
